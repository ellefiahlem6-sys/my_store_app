# 🛒 Retail Sales Dashboard

## 📌 Project Overview
An interactive web application built with Streamlit to analyze retail sales data. It helps store owners track key performance indicators (KPIs), visualize sales trends, and filter data by region and product category.

## 🎯 Business Value
- Provides a clear overview of total sales, average order value, and top products.
- Helps identify best-performing regions and products.
- Enables data-driven decisions for inventory and marketing.

## 🛠️ Tech Stack
- Python
- Pandas
- Matplotlib / Seaborn
- Streamlit
